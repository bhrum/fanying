# Contributing

1. Open or reference an Issue before substantial work.
2. Make changes only in your fork or an authorized branch.
3. Run the repository tests through GitHub Actions.
4. Open a Draft pull request and include the Issue, permission changes, Tool Contract changes, and artifact changes.
5. Never include credentials, private logs, tokens, or user data.

Pull requests from forks are tested with a read-only token and no secrets. Merging a pull request does not publish a release.
